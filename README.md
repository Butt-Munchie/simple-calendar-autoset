Autoset client settings for FoundryVTT Simple Calendar Reborn on load

**Heads Up! This module has been vibe coded to hell and back.**

# Functionality
This module, when enabled, will automagically set the following settings when a user enters the world.
- Open on Load = True
- Open Compact = True
- Remember Position = True
- Remeber Compact Position = True
- Persistent Open = True

No world reload is required.

# Dependencies
This module is dependent on [Simple Calendar Reborn](https://github.com/Fireblight-Studios/foundryvtt-simple-calendar).

# Macro
A macro is also included to do the same functionality manually if desired. Sometimes things can be stubborn and get stuck, so this macro is a last resort.
